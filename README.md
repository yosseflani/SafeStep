# 🦯 SafeStep

### אפליקציית AI חכמה לעיוורים ולקויי ראייה

### לזיהוי מכשולים בזמן אמת באמצעות Flutter ו־YOLOv8

---

# 📖 אודות הפרויקט

SafeStep היא אפליקציית מובייל שפותחה באמצעות Flutter ומיועדת לעיוורים ולקויי ראייה.

האפליקציה מזהה מכשולים בזמן אמת באמצעות מצלמת הטלפון ומתריעה למשתמש באמצעות:

* 🔊 התראות קוליות
* 📳 רטט
* 🚨 צפצופי אזהרה
* 🎤 פקודות קוליות

המטרה המרכזית של הפרויקט היא לסייע בהתמצאות בטוחה יותר בסביבה יומיומית באמצעות טכנולוגיות בינה מלאכותית וראייה ממוחשבת.

# 🧠 מערכת חישוב סיכון חכמה

לכל אובייקט מחושב ציון סיכון בין 0 ל־100 לפי:

* 📦 סוג האובייקט
* 📏 גודל האובייקט בתמונה
* 📍 מיקום האובייקט במסך
* 🎯 רמת הביטחון של הזיהוי
* ↗️ האם האובייקט מתקרב
* 📈 קצב שינוי הגודל
* 🏃 תנועה יחסית בין המשתמש לאובייקט

# 🚶 זיהוי תנועה יחסית

האפליקציה משלבת נתוני תנועה מהמכשיר עם ניתוח הווידאו.

מטרת המנגנון היא לצמצם התראות שווא כאשר:

* המשתמש עומד במקום

כך ההתראות מתמקדות במצבים בעלי פוטנציאל סיכון אמיתי.
